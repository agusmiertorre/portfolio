Acerca de mí

AI Native, data mindset, mentalidad de founder

Soy AI Native Professional Developer: potencio cada proyecto con IA (Claude, ChatGPT, Gemini) integrada a mi flujo de trabajo, no como un atajo puntual sino como parte del método — para desarrollar más rápido, automatizar tareas repetitivas y resolver problemas con criterio. Estudio la Tecnicatura Universitaria en Gestión y Análisis de Datos en Organizaciones (FCE – UBA), y eso se nota en cómo trabajo: estructuro e interpreto datos antes de decidir, no decido "a ojo".

Soy adaptable, curioso y cómodo en entornos cambiantes: prefiero entender el problema de negocio antes que aferrarme a una solución técnica, y disfruto la autonomía de armar algo de punta a punta, con mentalidad de founder más que de perfil puramente backend. El impacto que busco no es solo "que funcione", sino que resuelva algo real para quien lo usa.

Esa forma de trabajar se formó en la práctica: llevo más de 4 años como facilitador tecnológico, liderando talleres y proyectos educativos de robótica y programación para jóvenes, con metodología de aprendizaje basado en proyectos (PBL) — consignas abiertas, error productivo, iteración rápida y una entrega final donde cada equipo defiende lo que construyó. De ahí viene mi capacidad para liderar un proyecto de principio a fin y comunicar lo técnico con claridad.

Lo que traigo a un equipo: resolución de problemas, pensamiento crítico y trabajo colaborativo — y la costumbre de tomar un problema complejo, ordenarlo con datos e IA, y convertirlo en algo que funciona y se puede medir.

Datos & Automatización

Sincronización de Pedidos E-commerce a Google Sheets

Problema: los pedidos de una tienda en Tienda Nube se cargaban a mano en distintas planillas por sede, con demoras y errores de tipeo que afectaban el seguimiento. Solución: diseñé y lideré un sistema con Apps Script que consume la API de Tienda Nube y propaga cada pedido nuevo automáticamente a múltiples planillas y sedes, con la estructura de datos lista para reportes. Resultado: carga manual eliminada y datos consistentes y en tiempo real para todo el equipo.

  • Google Apps Script
  • API REST
  • Google Sheets
  • E-commerce
  • Automatización

App de Votación para Armado de Cursos

Problema: armar los cursos electivos de ~100 alumnos a criterio propio no reflejaba sus intereses reales ni la afinidad entre compañeros. Solución: desarrollé de punta a punta una app de votación en Google Apps Script que releva preferencias y afinidad entre estudiantes, y estructura esos datos como input directo para la asignación. Resultado: cursos armados con datos en vez de intuición, y un proceso que se repite cada ciclo sin trabajo manual.

Datos & Automatización

Modernización del Portfolio de Apps Script

Problema: varios proyectos internos de Apps Script vivían dispersos, sin control de versiones ni historial de cambios, lo que hacía frágil cualquier mejora. Solución: lideré la migración de ese portfolio a un flujo versionado con Git y GitHub, documentando cada script y ordenando el código para que fuera mantenible. Resultado: historial de cambios trazable, menor riesgo al iterar y una base lista para que otros puedan sumarse a mantenerla.

  • Google Apps Script
  • Git & GitHub
  • Versionado
  • Documentación técnica
